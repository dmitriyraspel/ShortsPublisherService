# Task Contract — ShortsPublisherService

**Версия:** 1.1

## 1. Назначение

Сервис обрабатывает одну задачу за запуск и выполняет реальную публикацию видео в YouTube Shorts через проверенный UI-сценарий Appium. Очередь, планирование и повторы остаются ответственностью внешнего оркестратора.

**Dry run отсутствует.** Запуск задачи может привести к реальной публикации.

## 2. CLI

```powershell
& ".\tools\dotnet\dotnet.exe" run -- `
  --file ".\videos\clip.mp4" `
  --caption "Caption for the Short" `
  --task-id "task-123" `
  --result-file ".\results\task-123.json"
```

Аргументы:

| Аргумент | Обязателен | Назначение |
|---|---|---|
| `--file PATH` | Да | Путь к исходному видео |
| `--caption TEXT` | Нет* | Подпись Shorts |
| `--task-id ID` | Нет | Идентификатор задачи, отражаемый в результате |
| `--result-file PATH` | Нет | Дополнительный файл JSON-результата |
| `--publish-video-youtube` | Нет | Оставлен для совместимости; публикация теперь является обычным поведением |
| `--help`, `-h` | Нет | Справка |

*Если `--caption` не передан, используется `Caption` из соседнего JSON-файла, затем `Title` для совместимости со старыми файлами, затем имя видео без расширения. Подпись ограничивается 100 символами.

Поддерживаемые расширения: `.mp4`, `.mov`, `.m4v`. Файл должен существовать и быть непустым. Исходное видео на компьютере не удаляется.

## 3. Метаданные

Для `clip.mp4` необязательный файл метаданных — `clip.json`:

```json
{
  "Caption": "Caption for the Short"
}
```

Для совместимости также принимается поле `Title` как запасной источник подписи. Остальные поля sidecar не управляют UI-сценарием: проверенный поток задаёт Public visibility и выбирает «Not made for kids».

## 4. Обработка

1. Разобрать аргументы и загрузить `appsettings.json`/переменные окружения.
2. Проверить путь, расширение и размер файла.
3. Разрешить подпись и вычислить SHA-256 исходного видео.
4. Проверить доступность настроенного Android-устройства через ADB.
5. Передать видео на устройство и обновить медиатеку.
6. Запустить проверенный сценарий YouTube UI: Create → Shorts → Gallery → выбор видео → редактор → подпись → Public → Not made for kids → Upload.
7. Наблюдать UI до 10 минут и считать публикацию успешной только при наличии явных сигналов подтверждения YouTube.
8. Вывести один JSON-результат в stdout; при `--result-file` сохранить тот же JSON в файл.

XML/PageSource используется только в памяти для анализа состояния UI. Диагностические XML/PNG и файлы снимков не создаются. Технические сообщения и ошибки направляются в stderr, чтобы не загрязнять JSON в stdout.

## 5. Результат

Поля JSON сериализуются с именами свойств C# (PascalCase):

| Поле | Тип | Назначение |
|---|---|---|
| `TaskId` | `string?` | Идентификатор задачи |
| `Status` | `string` | Итоговый статус |
| `Success` | `bool` | Операция завершилась успешно |
| `Published` | `bool` | Публикация подтверждена |
| `File` | `string?` | Абсолютный путь к исходному файлу |
| `Message` | `string` | Краткое описание результата |
| `Sha256` | `string?` | SHA-256 исходного файла, если вычислен |
| `StartedAtUtc` | `DateTimeOffset` | Начало обработки |
| `CompletedAtUtc` | `DateTimeOffset` | Завершение обработки |

Пример подтверждённой публикации:

```json
{
  "TaskId": "task-123",
  "Status": "published",
  "Success": true,
  "Published": true,
  "File": "C:\\Videos\\clip.mp4",
  "Message": "YouTube confirmed publication.",
  "Sha256": "…",
  "StartedAtUtc": "2026-10-22T12:00:00+00:00",
  "CompletedAtUtc": "2026-10-22T12:01:00+00:00"
}
```

### Статусы

- `published` — обнаружены явные сигналы подтверждения YouTube.
- `upload_failed` — UI показал ошибку загрузки.
- `publication_unconfirmed` — за отведённое время явное подтверждение не получено.
- `publication_unknown` — после нажатия Upload состояние UI не удалось прочитать; результат неоднозначен.
- `failed` — ошибка подготовки или выполнения до получения итогового результата публикации.
- `invalid_arguments` — неверные аргументы командной строки.

Коды завершения: `0` — публикация подтверждена; `1` — ошибка или публикация не подтверждена; `2` — неверные аргументы. При `publication_unknown` и `publication_unconfirmed` нельзя автоматически повторять задачу без внешней проверки: это может создать дубликат.

## 6. Настройки и ограничения

`appsettings.json` содержит `Publisher:AdbPath`, `Publisher:DeviceId`, `Publisher:AndroidMediaDirectory` и `Publisher:AppiumServer`. Переменные окружения с префиксом `SHORTSPUBLISHER_` могут переопределять значения.

Сервис не реализует очередь и автоматические повторы. UI-селекторы и переходы основаны на проверенном сценарии приложения; обновление YouTube может потребовать отдельной проверки совместимости.
